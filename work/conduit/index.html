Conduit API

Did the article survive?

A delete request with an invalid token returns 401. A second request answers the more important question for the author. Is the article still there?

Course-based Playwright suitePlaywright · API · Authorization

The risk

An error can hide a deletion

The response to an unauthorized request could look correct even if the application deleted the article. An author should still be able to retrieve the original article.

The experiment

Read the same slug back

The test starts with a seeded article. It sends a delete request using an invalid token, expects a 401 with an error, then fetches the article by slug. The read must return 200 and the original slug.

The comparison

Check what a real deletion looks like

The owner’s test expects a 204 after deleting the article. Both the following read and a repeated delete must return 404. The differing read results distinguish a rejected delete from a successful one.
