An approval belongs to one CV

A candidate has reviewed and approved a CV. If its text changes before export finishes, the edited version must stay out of the export folder.

Independent public projectData integrity · Regression test

The risk

The file can change between checks

The approval belongs to the exact text the candidate reviewed. Checking that a review exists is insufficient if a later edit can reach the exported file.

The experiment

Place the edit inside the export path

The test starts with a fictional approved CV and invokes the real approval check. Just after the check returns its result, a test hook appends an unreviewed statement to the CV. The exporter then continues with a changed file.

The evidence

Inspect the destination after the error

The exporter must reject the change with the expected error. The test also reads the destination directory and expects it to be empty. This catches a partial export even if the error message looks correct.
