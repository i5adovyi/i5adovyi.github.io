Playwright walkthrough

Testing draft recovery

A form can reopen on the right step and still lose the last edit. This browser test checks both the step and the exact value the candidate entered.

What the test checks

  1. 01

    Change the role

    The sample starts with QA Engineer. The test enters QA Automation Engineer, saves the draft, and waits for the review step.

  2. 02

    Reload the page

    After a real reload, the Review draft heading must be visible and the summary must show the new role.

  3. 03

    Return to the field

    The test selects Edit and checks the textbox itself. The candidate can continue with the saved value.
